# Golf Ball Inventory Management System
A Java-based Golf Ball Inventory Management System that helps users track and manage their golf ball inventory. Users can add new golf balls with specific details (brand, model, grade, color), remove balls from inventory, and view their current stock levels. The project uses Java with Swing for creating a user-friendly graphical interface, connects to a MySQL database through JDBC for persistent data storage, and features both console-based and GUI implementations for flexibility in user interaction. The application handles data validation, provides success notifications, and includes inventory filtering capabilities to help users manage their golf ball collection efficiently.
